# John Paul Verdad — Developer Portfolio

Responsive single-page portfolio made with **HTML, CSS, and vanilla JavaScript**. No npm, backend, or build step required.

## Getting started
Open `index.html` in a browser, or use VS Code Live Server. Deploy the folder's contents to GitHub Pages or any static hosting provider.

## Features
- Responsive navigation with mobile menu and keyboard Escape support
- Dark/light toggle with saved preference
- Portfolio sections: Home, About, Skills, Projects, Contact
- Animated project previews created with CSS (no fake screenshots)
- Scroll indicator, active navigation section, subtle reveal animations
- Reduced-motion accessibility support, visible keyboard focus, skip link

## Customize
- **Name, headlines, bio, skills, project descriptions:** `index.html`
- **Colors and layout:** `CSS/style.css` (`:root` and the appended 2026 refinement block)
- **Menu, theme, animation and navigation:** `JAVASCRIPT/scripter.js`
- **Social links:** Search for `github.com/jp12345q` and `twitter.com/jonpuroyohane` in `index.html`

External resources: Google Fonts and Font Awesome via CDN. The site remains usable without JavaScript except interactive enhancements. No contact form is included because no receiving email or form endpoint was provided.
